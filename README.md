# baseConverter
People can use this tool to convert values in one base to another. It supports bases 1 to 16.

# How it works
The tooltip above the keys already give explanations as to what you should do, but here are the steps of how it works:
<ol>
  <li>You key in the base of number you want to convert. Enter 1 value, and use the letter keys for 11~16. If you want to use base 10, enter 0. If you want to use bases 1~9, enter the respective number.</li>
  <li>Then enter the number in the base you wrote in step 1.</li>
  <li>After that you will enter the base value you want to convert the number to.</li>
  <li>After that you will see the conversion result. Click on Confirm to start another conversion process.</li>
</ol>
